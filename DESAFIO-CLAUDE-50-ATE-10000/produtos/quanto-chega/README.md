# Quanto Chega: compare quantos reais chegam ao enviar dólar, euro ou libra para o Brasil

**Usar (grátis, sem cadastro):** https://htmlpreview.github.io/?https://github.com/Matheuszinhorn/Matheuszinhorn/blob/ccr-fb47334b-mm7jqd/DESAFIO-CLAUDE-50-ATE-10000/produtos/quanto-chega/index.html?src=github

Mostra, por serviço (Remitly, Wise, Instarem, Western Union, Xoom, PayPal, OFX):
- quantos reais chegam;
- a taxa;
- a margem sobre o câmbio comercial;
- a idade de cada cotação.

Exemplo medido em 23/10/2026 para US$ 1.000: entre o melhor e o pior serviço, a diferença foi de R$ 269,64 a R$ 275,90, conforme o horário.

**Limites:** os dados vêm da API pública de comparação da Wise, que também aparece na lista. As cotações não são coletadas no mesmo instante. O IOF da entrada no Brasil pode não estar incluído. Confira no app do serviço antes de enviar.
