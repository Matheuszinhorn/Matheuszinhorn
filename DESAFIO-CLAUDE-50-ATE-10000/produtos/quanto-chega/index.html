Quanto Chega

Você vai mandar dinheiro do exterior para o Brasil? Veja, ao vivo, quantos reais chegam por serviço, já descontadas a taxa e a margem no câmbio de cada um.

Resultado

Os valores vêm da API pública de comparação mantida pela Wise, que também aparece na lista. É uma fonte com interesse próprio: confira a cotação final no app de cada serviço antes de enviar. Na entrada no Brasil pode incidir IOF (em geral 0,38% em transferências de pessoa física), que nem sempre está incluído nas cotações.

Isto ajudou?

Estamos avaliando um alerta por e-mail quando a cotação de um serviço passar de um valor escolhido. Ele ainda não existe. Se você usaria, diga abaixo: é isso que decide se ele será feito.

O botão do alerta abre uma Issue pública no GitHub (é preciso ter conta). Não inclua dados pessoais.

Sem cadastro e sem anúncios. Os links para os serviços são links comuns (sem comissão) até que exista um programa de indicação aprovado; quando houver, isso será indicado aqui. Não é recomendação financeira. Feito com auxílio de IA. Código aberto no GitHub.
