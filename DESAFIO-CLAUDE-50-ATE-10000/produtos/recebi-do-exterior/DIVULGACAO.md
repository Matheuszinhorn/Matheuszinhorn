# Texto para divulgação (comunidades de devs; em uma única postagem, sem spam)

**Título:** Fiz um conversor grátis de dólar → real para o Carnê-Leão (PTAX do BC, regra da 1ª quinzena)

Quem recebe de fora como PF precisa converter cada pagamento pela cotação do BC e lançar no Carnê-Leão Web todo mês. Cada fonte fala uma coisa: uns dizem que é a cotação do dia, outros que é a PTAX de compra do último dia útil da 1ª quinzena do mês anterior.

Fiz uma página que:
- busca a PTAX oficial direto no Banco Central para cada recebimento;
- aplica a regra da 1ª quinzena e mostra quanto daria pela cotação do dia, para comparar;
- soma por mês e mostra o vencimento do DARF;
- exporta CSV;
- roda inteira no navegador: os valores não saem do seu computador.

Link: https://htmlpreview.github.io/?https://github.com/Matheuszinhorn/Matheuszinhorn/blob/ccr-fb47334b-mm7jqd/DESAFIO-CLAUDE-50-ATE-10000/produtos/recebi-do-exterior/index.html

Não é aconselhamento fiscal. Se achar erro ou quiser um relatório anual para a declaração, tem um botão na página. Feito com ajuda de IA.
