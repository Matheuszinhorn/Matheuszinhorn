# Local Site Kit Lite: a free one-file website for barbershops

A free, fast, mobile-first website template for local businesses, in **English, Spanish and Portuguese**. It's a single HTML file under 10 KB, has no build step and no dependencies, and you can host it free.

![Local Site Kit](docs/cover.png)

## What's included (free, MIT)
- `templates/barbershop-en.html`, `barbershop-es.html` and `barbershop-pt.html`
- A "Book on WhatsApp" button with a pre-filled message
- Services and prices, reviews, opening hours, a Google Maps directions link and click-to-call
- Automatic dark mode and LocalBusiness schema.org markup for local SEO

Live preview: [English](https://htmlpreview.github.io/?https://github.com/Matheuszinhorn/local-site-kit-lite/blob/main/templates/barbershop-en.html) · [Español](https://htmlpreview.github.io/?https://github.com/Matheuszinhorn/local-site-kit-lite/blob/main/templates/barbershop-es.html) · [Português](https://htmlpreview.github.io/?https://github.com/Matheuszinhorn/local-site-kit-lite/blob/main/templates/barbershop-pt.html)

## Use it in 3 steps
1. Download a template and open it in any text editor.
2. Replace the business name, services, prices, hours, address and WhatsApp number. Search for "Your City" and "+1 555".
3. Drag the file, renamed to `index.html` inside a folder, to [Netlify Drop](https://app.netlify.com/drop), or publish it with GitHub Pages or Cloudflare Pages.
