# Distribuição — Local Site Kit Lite (pesquisa de 22/10/2026)

| Canal | Público | Regra verificada | Precisa de | Situação |
|---|---|---|---|---|
| Tópicos e descrição do repositório no GitHub | Busca do GitHub e do Google | — | Repositório acessível à integração | **Executável por Claude** assim que houver acesso |
| Show HN (Hacker News) | Desenvolvedores, global | As regras oficiais excluem "quickly generated one-off projects" e exigem algo "non-trivial" | Conta HN | **Não se aplica**: um template simples não se qualifica. Não postar |
| Reddit r/webdev e r/SideProject | Desenvolvedores, global | Não foi possível ler as regras (o reddit.com bloqueia a leitura automática). Autopromoção costuma ser limitada; verificar antes | Conta Reddit do proprietário | Não executável por Claude |
| TabNews | Desenvolvedores, Brasil | Aceita publicação de projetos próprios | Conta do proprietário | Não executável por Claude |
| DEV.to (artigo tutorial: "site de barbearia em 1 arquivo, sem build") | Desenvolvedores, global | Conteúdo educativo é permitido | Conta do proprietário (login pelo GitHub) | Não executável por Claude. Texto pode ser preparado |
| Listas "awesome" no GitHub | Desenvolvedores | Cada lista tem seu CONTRIBUTING | PR em repositório de terceiros | **Bloqueado pela DEC-015** ("não altere outros repositórios") |

Conclusão: o único canal de distribuição executável sem nenhuma conta é a **otimização do próprio repositório** (tópicos, descrição e README voltado para busca). Os demais exigem uma conta pessoal do proprietário ou PRs em repositórios de terceiros, o que a DEC-015 proíbe.
